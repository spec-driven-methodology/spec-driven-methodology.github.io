Spec-Driven Methodology

SDM treats methodology as specs: written once, verified by machine, with every derived output generated automatically.

Explore the layers How it works

What is SDM?

A single, machine-verifiable chain of methodological artifacts — independent of who performs the steps: a human or an agent.

ONTOLOGY

One graph

Nodes of any kind — skills, topics, concepts, talks — and their relationships in a single graph.

PROFILE

Selection & threshold

What is selected from the ontology and to what threshold. The profile defines the target.

COVERAGE

Fixed gap definition

What is missing, computed by a fixed measure. Identical across all implementations.

# spec.yaml — written once
ontology: ./ontology
profile: junior-backend
coverage: fixed-measure

# everything below is generated
export:
  web # player
  obsidian
  cli
  • ✓
    SpecificationOntology + profile + gap definition. Changes rarely.
  • ✓
    ComputationCoverage by a fixed measure. Iterates.
  • ✓
    PresentationExport anywhere: MCP, Obsidian, web, CLI, documents. Fully open.
