Theme Reference

SDM Design System

CSS palette, typography, layout components, and interactive elements used across the SDM site. All components work at file:// — no frameworks, no CDN dependencies beyond the JetBrains Mono font.

Palette

CSS custom properties — the entire site is driven by these 11 tokens.

BACKGROUND

--bg: #2b2b2b

Page background. Used on body and .code blocks.

SURFACE

--surface: #313335

Card and container background. Borders: --border: #4a4a4a.

SURFACE-2

--surface-2: #3c3f41

Hover, input, bar backgrounds. Deeper than surface.

KEYWORD

--keyword: #cc7832

Accent orange. Buttons, section kickers, flow step numbers.

METHOD

--method: #ffc66d

Link yellow. Inline code, links, active states.

STRING

--string: #6a8759

Green. Code string tokens, OK states, topic kind tags.

NUMBER

--number: #6897bb

Blue. Depth values, gradient end, product kind tags.

FIELD

--field: #9876aa

Purple. Concept/person kind tags, JSON property keys.

COMMENT

--comment: #808080

Gray. YAML comments, dim separators.

OK / WARN

--ok / --warn

Coverage status: green (#6a8759) and amber (#f0a030).

TEXT

--text / --text-dim

Primary #a9b7c6 and muted #9a9a9a.
