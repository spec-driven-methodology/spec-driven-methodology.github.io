# spec-driven-methodology.github.io

Организационный сайт методологии SDM (Spec-Driven Methodology). Собирается GitHub Pages (Jekyll) автоматически при пуше в `main`.

## Структура

- `index.md` — главная, текст из `ONE_PAGER.md` методологии
- `_config.yml` — конфигурация Jekyll
- `roadmap.md` — заглушка

## Локальная разработка

```bash
bundle install
bundle exec jekyll serve
```
