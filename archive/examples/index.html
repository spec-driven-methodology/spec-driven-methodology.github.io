Какие из перечисленных утверждений о ключевом слове volatile в Java верны?
☑ Гарантирует видимость изменений между потоками correct
☐ Устраняет необходимость в синхронизации для составных операций
☑ Запрещает переупорядочивание операций чтения/записи correct
☐ Обеспечивает атомарность операций инкремента
Explanation: volatile гарантирует видимость и порядок, но не атомарность и не заменяет синхронизацию для read-modify-write.
