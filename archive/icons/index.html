Иконки AI / Agent-first

Набор переосмыслен вокруг ключевой идеи SDM: AI-агент ведёт методологию как граф компетенций. Искра ✦ — маркер ИИ, орб — агент, узлы — навыки.

Agent Orb

Белый орб — агент, золотая искра внутри — ИИ, два узла по краям — навыки, которые агент ведёт. Основной знак SDM: agent-first методология.

Применение — правила

Палитра и рекомендации по использованию знака.

#5b8cffbrand
#8a6cffbrand-2
#ffc44dgold / spark
#eef1f7white / orb
#0d0f14bg
  • Искра ✦ — единственный маркер ИИ. На знаке — золотая (#ffc44d), в монохроме — currentColor.
  • Смысл: орб = агент, искра = ИИ, узлы = навыки. «Агент ведёт граф» — основная метафора SDM.
  • Градиент знака 135°: #5b8cff → #8a6cff. Не перекрашивать, не менять пропорции.
  • Линейный набор: stroke 2 на viewBox 24, скругления round, цвет через currentColor.
  • Размеры: 16–32 px — favicon/вкладки, 24 px — интерфейс и документация, 64 px+ — обложки.
  • Файлы: logo-agent-orb.svg, logo-spec-spark.svg, favicon.svg, набор — icons/*.svg.
