01 Онтология — 13 навыков в графе, 8 в фокусе

Узлы любых видов в едином графе. Каждый навык — YAML-файл: id, name, description и опциональные связи с другими узлами.

ontology/skills/core-java.yaml

Core Java

JVM, типы, ООП, коллекции, многопоточность, лямбды, Stream API, исключения, аннотации.

ontology/skills/spring-framework.yaml

Spring Framework

IoC/DI, Spring Boot, MVC, REST, безопасность, транзакции, JDBC/JPA, тестирование.

ontology/skills/spring-ai.yaml

Spring AI

ChatClient, модели, advisors, tool calling, embeddings, vector stores, structured output.

04 Экспорт — test-java-developer-senior.json

Всё производное генерируется: тестовый пакет для агентов и внешних систем — один артефакт, без рукописных отчётов.

{
  schemaVersion: "sdm.export.test/v1",
  profile: "java-developer", level: "senior", threshold: 0.7,
  requirements: [ /* 8 навыков · depth · weight */ ],
  questions: [ /* 32 вопроса · 3 типа */ ]
}
32 вопроса 8 навыков порог 70% 12 терминов глоссария
Это один формат экспорта. Те же спецификации генерируют другие выходы: export matrix, export kit, export learning --format course, export mermaid — слой представления полностью открыт.
